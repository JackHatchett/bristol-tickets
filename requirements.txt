# Bristol — the board and its agents

# else they need is the standard library (sqlite3, argparse, pathlib, json,
# csv, hashlib, subprocess — see src/tools/ticket_tools/README.md 3a for why
# sqlite3 specifically is always used as a library, never a CLI subprocess
# call).
#
# Install:
#   pip install -r requirements.txt
#   (macOS with a Homebrew-managed Python may need --break-system-packages)
#
# The rest of src/tools/ is a toolkit the agents reach for and the board does
# not: photo processing, job-description scraping, OCR. Those live in
# requirements-tools.txt, installed only when you want one of them.
