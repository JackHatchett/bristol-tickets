# Writing Tools

Machinery for capturing how a person writes and scaffolding a draft.

## Index

- **`voice_capture.md`** — the sample-first method: mine or elicit specimens,
  distil each into a technique card. Load it when a deliverable must sound like
  a specific person.
- **`plot_alignment.py`** — the plot alignment sheet generated from a novel's
  tiered plot notes, and the writes that carry a change in the notes into the
  sheet without moving a placed beat. The procedure around it is
  `src/skills/syncing-the-plot-alignment-sheet/SKILL.md`.
- **`house_style.py`** — the house style a copyediting pass applies, read
  from `agents.<agent>.house_style`, and its rules files, base style first; a
  style set but not built exits 2 with the styles built. The procedure around it is
  `src/skills/copyediting-to-a-house-style/SKILL.md`.
- **`templates/`** — `beat-sheet-chapter.md`, `draft-chapter.md`,
  `draft-scene.md`. Fill-in structure, no content.

## Using these

- **Point a skill at `voice_capture.md` rather than restating the method.** The
  owning agent's charter and skills own whose voice, which project, and what the
  technique inventory contains.

`src/skills/voice-distillation/SKILL.md` uses the pattern.
